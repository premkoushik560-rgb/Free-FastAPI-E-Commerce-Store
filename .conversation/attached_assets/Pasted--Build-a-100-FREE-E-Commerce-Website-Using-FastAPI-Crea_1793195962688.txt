# Build a 100% FREE E-Commerce Website Using FastAPI

Create a complete, working E-Commerce application with a FastAPI backend and a responsive frontend. This is a student portfolio project, and the entire development process must use free and open-source tools.

## 1. Strict Free-Only Requirements

- Do not use paid APIs, paid AI services, paid templates, premium components, or paid plugins.
- Do not require a credit card, paid subscription, or payment to run the project locally.
- Do not use paid product-image APIs.
- Do not require a paid database or paid hosting service.
- Do not use Stripe, Razorpay, or other real payment gateways. Implement a simulated payment system for demonstration purposes.
- Do not use services that require a paid plan or paid API key.
- Do not recommend upgrading to a paid plan to complete the project.
- Use only free and open-source libraries wherever possible.
- Build the project so that it works on my Windows laptop using Python.
- If an optional service has free-tier limits or requires registration, avoid it when a local alternative is available.
- Never claim that a third-party hosting service is permanently free. Local development must remain fully functional without hosting.

## 3. Website Features

Create a professional, responsive online shopping website with:

1. Home page with a navigation bar, hero section, categories, featured products, and footer.
2. Product listing page with search, filtering, sorting, and pagination.
3. Product details page with description, price, image, and stock information.
4. Registration and login pages.
5. Shopping cart with quantity updates and item removal.
6. Checkout page with shipping details and simulated payment.
7. Order confirmation page.
8. User profile and order history.
9. Admin dashboard with product, category, stock, and order management.
10. Responsive mobile and desktop layouts.

All buttons and forms must work. Do not create a static-only website.

## 4. Backend API

Create a REST API under /api/v1.

Authentication:
- POST /api/v1/auth/register
- POST /api/v1/auth/login
- GET /api/v1/auth/me

Products:
- GET /api/v1/products
- GET /api/v1/products/{product_id}
- POST /api/v1/products
- PUT /api/v1/products/{product_id}
- DELETE /api/v1/products/{product_id}

Categories:
- GET /api/v1/categories
- POST /api/v1/categories

Cart:
- GET /api/v1/cart
- POST /api/v1/cart/items
- PATCH /api/v1/cart/items/{item_id}
- DELETE /api/v1/cart/items/{item_id}

Orders:
- POST /api/v1/orders
- GET /api/v1/orders
- GET /api/v1/orders/{order_id}

Admin:
- GET /api/v1/admin/dashboard
- GET /api/v1/admin/orders
- PATCH /api/v1/admin/orders/{order_id}/status

Health:
- GET /health

Use appropriate HTTP status codes, JSON responses, input validation, error handling, and authorization.

## 6. Security

- Hash passwords instead of storing plain-text passwords.
- Use expiring JWT access tokens.
- Validate all user input.
- Protect customer information and order history.
- Restrict admin operations to authorized administrators.
- Never allow users to register themselves as administrators.
- Never hard-code real secrets.
- Store configuration in environment variables when needed.
- Include .env.example without real credentials.
- Do not upload secrets, virtual environments, or private data to GitHub.
